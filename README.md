# 📊 Data Professional Survey Breakdown — Power BI Dashboard

A Power BI dashboard built to analyze survey responses from **630 data professionals** worldwide. The goal was to uncover real patterns in salaries, job satisfaction, programming language preferences, and how hard it actually is to break into the data field.

---

## 🔍 What This Dashboard Covers

| Metric | Insight |
|---|---|
| Total Survey Takers | 630 |
| Average Age | 29.87 years |
| Top Country | United States |
| Highest Paid Role | Data Scientist |
| Most Used Language | Python |
| Work/Life Happiness | 5.74 / 10 |
| Salary Happiness | 4.27 / 10 |

---

## 📌 Key Findings

- **Data Scientists earn the most** on average, followed by Data Engineers and Data Architects.
- **Python is the dominant language** by a wide margin across all job titles. R comes in second, with JavaScript and Java barely registering.
- **Breaking in isn't easy** — 42.7% of respondents rated it "Neither Easy nor Difficult", while 24.76% called it Difficult and 6.98% said Very Difficult. Only a small fraction found it easy.
- **Salary satisfaction is low** — professionals rate their happiness with salary at just 4.27/10, which is noticeably lower than their work/life balance score of 5.74/10.
- **US, India, UK, and Canada** are the top represented countries in the survey.

## 🛠️ Tools Used

- **Power BI Desktop** — for data modeling, DAX calculations, and visual design
- **Power Query** — for data cleaning and transformation
- **DAX** — for custom measures (averages, counts, ratings)
